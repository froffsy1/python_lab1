ОПИСАНИЕ РАБОТЫ:
Скрипт собирает данные об ОС, пользователе и системе через модули platform, os, sys и datetime, объединяет их в один словарь, выводит в консоль и сохраняет в файл system_info.json.

СОБРАННЫЕ ДАННЫЕ 
os_info: название ОС; версия; дата релиза; архитектура процессора; имя компьютера в сети.
user_info: имя пользователя, под которым запущен скрипт; текущая дирекция; версия интерпретатора Python.
oser_info: количество логических ядер процессора; дата и время запуска скрипта.
